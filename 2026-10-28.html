1. Google DeepMind Genie 4: 실시간 월드 시뮬레이션 모델

출처: Google DeepMind 블로그 (10-27)

Genie 4는 새 월드 모델이다. 텍스트와 키보드로 장면을 실시간으로 바꾼다. 소리와 대화를 영상과 함께 생성한다. 실시간 월드 모델로는 처음이라고 DeepMind는 말한다. Gemini 3.8 Flash가 장면을 보고 목표를 단계로 나눈다. Gemini 4 Argon과 함께 로봇 과제도 시뮬레이션한다. 공개 범위는 신뢰 테스터 연구 미리보기이다. 파라미터, 벤치마크, 가격: 출처에 없음.

왜 중요한가. 로봇과 에이전트의 학습 환경을 만드는 도구가 된다. 오래 돌리면 물체 일관성이 흐려진다고 DeepMind가 직접 밝혔다.

2. Anthropic: Claude로 실제 소프트웨어의 치명적 취약점을 찾고 공격 코드를 만들었다

출처: Anthropic Frontier Red Team (10-27)

Anthropic은 공개하지 않은 내부 연구 모델을 썼다. Chrome에서 클릭 한 번으로 샌드박스 밖 코드 실행 체인을 만들었다. Chrome 156까지 이 작업으로 CVE 62건이 고쳐졌다. 그중 13건은 샌드박스 탈출이다. Safari 동일 출처 정책 우회, Android 잠금 화면 우회, Windows HTTP/3 원격 DoS(CVE-2026-33096), Linux MPTCP 원격 root 실행(CVE-2026-98432)도 보고했다. Linux 공격은 커널 포인터 유출에 48분, 명령 실행에 5분이 더 걸렸다.

왜 중요한가. 모델이 여러 취약점을 묶어 실제 공격을 만드는 수준에 왔다. Anthropic은 PR 단계 스캔을 권하고 Claude Code 보안 플러그인을 공개했다.

3. Anthropic: Claude로 신약 개발을 가속한 초기 결과

출처: Anthropic 연구 (10-27)

Anthropic은 제약·바이오 기업 6곳과 협업했다. Generate Biomedicines는 Claude Code로 CAR-T 설계를 만들었다. 한 설계는 표준보다 약 70% 짧다. 수용체는 약 10배 많이 나왔다. Divergence Labs에서 Claude는 약 한 달에 항체 설계 약 35,000개를 만들었다. Enveda 문서 1,061쪽 검토에서 Claude는 사람이 찾은 11건을 모두 찾았다. 사람이 놓친 7건도 찾았다. 검토 시간은 89% 줄었다. 대부분 결과는 전임상 단계이다.

왜 중요한가. LLM 에이전트가 분자 설계뿐 아니라 실험 운영과 규제 문서까지 맡는 사례이다. 수치는 모두 Anthropic과 협력사의 자체 보고이다.
