1. SenseNova-Loop-9B-Preview: 층을 두 번 돌리는 9B 루프 모델

출처: Hugging Face 모델 카드 (10-30 21:42 KST 공개, 10-31 확산)

이 모델은 텍스트와 이미지를 받아 텍스트를 낸다. 서로 다른 디코더 층은 32개이다. 4–27번 층(24개)은 같은 가중치로 두 번 돈다. 그래서 층 실행은 모두 56번이다. 저장 파라미터는 약 9B(9,656,250,480)이다. 추론 시 실효 파라미터는 약 14.6B라고 카드는 쓴다. 어텐션은 4개 층마다 선형 3개와 전체 1개를 섞는다. 학습 문맥은 최대 262,144 토큰이다. 라이선스는 Apache-2.0이다. 실행에는 Transformers 5.18.0과 trust_remote_code가 필요하다. 벤치마크(BIRD-Dev, Terminal Bench 2.1, WorkBuddy Bench 등)는 그림으로만 있다. 그래서 숫자는 출처에 없음. 가격: 출처에 없음. 기술 보고서는 아직 없다.

왜 중요한가. 가중치를 늘리지 않고 층을 다시 돌려 계산량을 늘리는 방식이다. 같은 메모리로 더 큰 모델처럼 쓸 수 있는지 시험할 수 있다. 판정: 지켜볼 만함. 점수 숫자와 보고서가 아직 없다. 10-31에 커뮤니티 GGUF·MLX 변환이 나왔다.

반응. HF 좋아요 105, 다운로드 566. HN 글은 찾지 못했다.

2. NVIDIA DeepSeek-V4.1-Flash-1017-NVFP4: Blackwell용 4비트 양자화판

출처: Hugging Face 모델 카드 (10-31 02:37 KST 공개)

원 모델은 552B 백본 MoE이다. 활성 파라미터는 prefill 8B, decode 16B이다. 196B Engram 메모리가 따로 있다. 문맥은 1M 토큰이다. NVIDIA는 라우팅 전문가(40개 층 × 384개)를 MXFP4에서 NVFP4(W4A4, 그룹 16)로 바꾸었다. Engram은 FP8에서 MXFP4로 바꾸었다. 이 단계는 손실이 있다. 크기는 약 475 GiB에서 약 400 GiB로 줄었다. 점수(원본 → NVFP4): GPQA Diamond 92.77 → 92.93, AA-LCR 80.41 → 80.19, SciCode 57.58 → 57.32, Terminal-Bench 2.1 81.81 → 81.11, MMMU-Pro 78.38 → 78.73. 라이선스는 MIT이다. Blackwell GPU에서만 돌고, vLLM PR #61530이 들어간 빌드가 필요하다. 시험 환경은 GB300 4장이다.

왜 중요한가. 큰 오픈 모델을 GPU 4장에 올리는 데 필요한 메모리를 줄인다. 점수 손실은 표에서 1점 안쪽이다. 판정: 써볼 만함(Blackwell 보유 시). 다른 GPU에서는 쓸 수 없다.

반응. HF 좋아요 84, 다운로드 715. HN 글은 찾지 못했다.

링크. Hugging Face

3. DeepSeek dsh-superagent: GitHub 요청에 스스로 반응하는 코딩 에이전트 시제품

출처: GitHub deepseek-ai (10-31 18:32 KST 생성)

dsh-superagent는 GitHub 저장소 하나를 맡는 코딩 에이전트이다. DeepSeek Harness용 번들로 나왔다. GitHub와 Feishu(선택)를 듣는다. 허가된 사람이 일을 맡기면 작업 항목을 만든다. 작업마다 별도 세션과 디렉터리에서 일하고, 원래 대화에 pull request 등으로 답한다. 웹 패널은 사람이 처리할 일만 보여 준다. README는 "공식 제품이 아닌 연구 시제품"이라고 쓴다. 코드 대부분은 코딩 에이전트가 만들었다고 쓴다. 함께 낸 설계 글은 Router 한 개와 여러 Worker 세션, 이벤트 기반 동작, Watchdog을 제안한다. 일부 설계는 시제품에 없다.

왜 중요한가. 항상 켜져 있는 팀용 에이전트를 사람 주의를 덜 쓰게 만드는 구조를 DeepSeek가 코드로 보여 주었다. 판정: 지켜볼 만함. 연구 코드이고 설정 단계가 많다.

4. nesformer: Qwen 가중치 안에 컴파일한 NES 컴퓨터

출처: Show HN · GitHub dbreunig (10-31 01:40 KST 게시)

nesformer는 NES의 6502 CPU, 2KB RAM, 카트리지 PRG-ROM을 Qwen3_5ForCausalLM 가중치로 만든다. 가중치는 학습하지 않았다. 컴파일러가 계산했다. 10-29 메인 Qwenputer의 컴파일러를 이어 쓴다. Gated DeltaNet 상태가 기계의 메모리이다. 공식 명령어 151개를 모두 지원한다. 화면(PPU)과 컨트롤러는 호스트가 맡는다. 시험 게임에서 프레임이 기준 6502 에뮬레이터와 같다. 한 프레임에 1–6초가 걸린다. NROM(mapper 0) 게임만 돈다.

왜 중요한가. 트랜스포머 가중치가 정확한 프로그램 실행기가 될 수 있다는 실험이다. 실용 에뮬레이터는 아니다. 판정: 지켜볼 만함.

5. Mika: 숨은 화면에서 앱을 대신 조작하는 Android AI 에이전트

출처: GitHub wangzan101 (10-29 생성, 10-31 GitHub 신규 저장소 상위)

Mika는 Android 앱이다. 사용자 말을 받아 보이지 않는 별도 화면에서 앱을 열고 누르고 입력한다. 사용자는 그동안 휴대폰을 계속 쓴다. 앱이 API를 열지 않아도 화면을 보고 조작한다. Mika 서버는 없다. 사용자가 자기 모델 API 키를 넣거나 ChatGPT·xAI·OpenRouter 계정으로 로그인한다. 기본 모드는 돈을 쓰기 전에만 묻는다. 대화마다 arm64 Linux 샌드박스에서 Python과 셸을 돌린다. Android 12 이상이 필요하고 14 이상을 권한다.

왜 중요한가. 휴대폰 앱을 대신 쓰는 에이전트를 오픈소스로 직접 설치할 수 있다. 화면 조작 권한이 크므로 키와 결제 설정을 조심해야 한다. 판정: 써볼 만함. APK가 있고 Apache-2.0이다.

반응. GitHub 별 2,674, 포크 433, Apache-2.0, Kotlin, 마지막 push 11-01. HN 글은 찾지 못했다.

8. VOLTA 정보 탈취 악성코드가 LLM으로 피해자 가치를 매긴다

출처: Cisco Talos (10-31)

VOLTA는 스스로 지워지는 Windows 정보 탈취 악성코드이다. 훔친 자료로 증거 묶음을 만든다. 훔친 Gmail, Uber Eats, DoorDash, Discord 세션으로 정보를 보탠다. 그 뒤 OpenRouter로 보내 "표적 평가"를 쓰게 한다. 출력에는 "얼마의 가치가 있는가"와 "보안 습관" 항목이 있다. 기본 모델은 anthropic/claude-opus-4.6이다. 거부 문구가 나오면 moonshotai/kimi-k2, google/gemini-2.5-flash로 넘어간다. 공격자 소유 서버는 쓰지 않는다.

왜 중요한가. 공격자가 상용 LLM API로 훔친 데이터를 자동 분류한다. 모델 거부는 다른 모델로 바꾸면 우회된다.
