1. LongCat-2.5: Meituan의 1.6T MoE 멀티모달 에이전트 모델

출처: LongCat 블로그 · Meituan 뉴스 · LongCat API 문서

Meituan이 11월 2일 LongCat-2.5를 발표했다. 총 파라미터는 1.6T이고 토큰당 약 48B를 활성화한다. 문맥은 1M 토큰, 최대 출력은 128K 토큰이다. 학습은 전부 중국산 가속기에서 했다고 Meituan은 밝혔다.

자체 표 기준 점수: Terminal Bench v2.1 88.4(GPT-5.6-Sol 88.8, Claude-Opus-5 89.1, DeepSeek-V4.1-Flash 90.6). BrowseComp 91.9(Claude-Opus-5 90.8). HLE w/ tools 63.1(Claude-Opus-5 64.7). DeepSWE v1.1 64.6(Claude-Opus-5 68.8). 이전 버전 LongCat-2.0의 DeepSWE v1.1 점수는 9.7이었다.

API 가격은 한시 할인가로 입력 $0.30, 캐시 입력 $0.006, 출력 $1.20(1M 토큰당)이다. W4A4 추론은 W8A8 대비 prefill 처리량을 43.3%, decode 처리량을 42.77% 높였다고 밝혔다. 오픈 웨이트 공개 여부는 출처에 없음. 확인 시각에 Hugging Face meituan-longcat 계정에 2.5 가중치는 없었다.

왜 중요한가. 중국산 칩으로 학습한 모델이 상용 최상위 모델과 비슷한 에이전트 점수를 냈다고 주장한다. 가격은 비교 모델보다 훨씬 낮다. 다만 비교 점수 다수는 공개 자료 인용이고, 일부는 자체 측정이다.

반응. HN에서 의미 있는 토론을 찾지 못했다. Reddit은 확인 실패.

2. Apriel Voice 27B Preview: 음성·추론·도구 호출을 한 모델로

출처: Hugging Face 모델 카드 · arXiv 2610.40738 (HF Papers 11-02 제출)

ServiceNow가 공개한 오픈 음성-언어 모델이다. Whisper large-v3-turbo 음성 인코더를 Gemma 4 26B-A4B 백본에 붙였다. 모델은 음성을 바로 받아 텍스트 답과 도구 호출을 만든다. 음성 합성은 외부 TTS가 맡는다.

τ-Voice pass@1은 65.51%, 평균 지연은 1.91초다. 비교 값은 GPT Realtime 2.1 69.82%·1.55초, Gemini-3.8 Live 84.19%·1.50초, Parakeet+Gemma 4-26B 3단계 구성 67.78%·3.01초다. EVA-X(대화 경험)는 74.13으로 표의 모든 모델보다 높다. LibriSpeech WER은 test-clean 2.23%, test-other 5.15%다. 텍스트 GPQA Diamond는 80.40으로 원 백본(77.80)보다 높다.

라이선스는 MIT다. 공식 vLLM 예시는 GPU 4장(H100 80GB 기준)과 262,144 토큰 문맥을 쓴다.

왜 중요한가. 오픈 2단계 음성 모델이 3단계(ASR+LLM+TTS) 구성과 비슷한 과제 성공률을 더 낮은 지연으로 냈다. 음성 상담 에이전트를 직접 운영하려는 팀에게 쓸 만한 기준점이다.

판정: 써볼 만함. 라이선스가 자유롭고 vLLM 서빙 설정이 카드에 있다. 다만 아직 Preview 판이다.

반응. Hugging Face 좋아요 63개, 다운로드 338회. HF Papers 추천 33개.

3. KVARK Sparkle 1.0 (27B): Qwen3.8-27B보다 생각 토큰을 줄인 미세조정 모델

출처: Hugging Face 모델 카드 · r/LocalLLaMA 공지(ReadmeX 요약, 11-02)

정확도는 GPQA Diamond 89.3(Qwen 89.4), AIME 93.3(94.0), LiveCodeBench v6 82.7(77.3), IFEval 91.3(92.4), MMLU-Pro 83.3(84.0)이다. 중앙값 추론 토큰은 34–67% 줄었다. H200 1장에서 답 하나의 중앙값 시간은 13.7초로, Qwen의 28.1초보다 짧다.

5. Heretic 2.0: 검열 제거 도구에서 범용 모델 수정 도구로

출처: GitHub p-e-w/heretic v2.0.0 (2026-11-01 22:03 KST) · HN

Heretic은 학습 없이 언어 모델의 거절 동작을 없애는 도구다. 2.0은 범용 플러그인 시스템, 수정자(modifier) 플러그인, 벤치마크 점수기, 헤드리스 실행을 넣었다. 제작자는 이제 아첨 줄이기와 "slop" 억제도 된다고 밝혔다. 1.x 설정 파일은 호환되지 않는다. 연구 기능은 별도 프로젝트 Lophius로 옮겼다.

판정: 지켜볼 만함. 성숙한 프로젝트다. 다만 2.0의 새 기능은 아직 검증 사례가 적다.

6. UNCUT: 문맥을 자르지 않는 7MB 헤드리스 코딩 에이전트 하네스

출처: GitHub Balanov/uncut

UNCUT은 Go로 만든 정적 바이너리 하나(7MB)다. 도구는 4개뿐이다. 입출력은 stdin/stdout이고, --json을 주면 NDJSON을 낸다. 문맥 압축이 없다. 모든 호출에 대화 전체를 보낸다. 공급자가 출력을 자르면 성공으로 보이지 않고 오류로 끝낸다.

OpenAI 호환 Chat Completions 엔드포인트를 쓰므로 로컬 서버와도 동작한다. 구현 코드는 837줄이다. 세션은 JSONL로 저장하고 다시 이어 갈 수 있다.

왜 중요한가. 기존 하네스는 문맥을 몰래 요약하거나 잘라서 결과를 흐리게 만들 수 있다. UNCUT은 CI 파이프라인과 에이전트 실험에서 재현성을 높인다. 대신 긴 작업은 토큰 비용이 커진다.

판정: 지켜볼 만함. 생성 하루 만에 별이 많이 붙었지만 버전은 0.1.1이다.

반응. GitHub 별 570개. 생성 2026-11-02 02:19 KST. 마지막 push 2026-11-03 05:58 KST. 라이선스 MIT.

링크. 저장소

7. Trail of Bits: Codex로 보안 수정 백포트를 며칠에서 몇 시간으로

출처: Trail of Bits 블로그 (2026-11-02) · HN

Trail of Bits는 Codex와 GPT-5.6으로 안정판 리눅스에 빠진 보안 수정을 찾고 옮긴다. 에이전트가 누락 수정 찾기, 패치 수정, 테스트, 제출 자료 작성을 한다. 사람은 검토하고 제출한다.

왜 중요한가. AI 버그 탐색이 빨라질수록 오래된 안정판의 취약점이 더 위험해진다. 이 글은 같은 AI로 수정 쪽도 빠르게 할 수 있다는 실제 수치를 준다.

9. HF Daily Papers 상위: FrameForge, R^2Orch

출처: Hugging Face Daily Papers (2026-11-02 목록)

FrameForge는 비디오 기반 모델을 이미지 생성에 쓴다. 조건 이미지와 목표 이미지 사이의 "가상 시간 간격"을 입력마다 다르게 고른다(Mixture of Temporal Experts). DreamBench, COCO2017, GEdit-Bench에서 비교 방법보다 낫다고 밝혔다. 구체 수치는 초록에 없음.

R^2Orch는 에이전트 오케스트레이터를 자기 대국(self-play)으로 개선한다. 실패를 스킬로 만들고, 스킬을 파라미터로 옮긴 뒤 스킬을 빼 나간다. 목표는 스킬 없이 배포하는 것이다. 12개 데이터셋에서 기준 방법보다 낫다고 밝혔다. 구체 수치는 초록에 없음.

왜 중요한가. R^2Orch는 스킬 카탈로그를 학습으로 흡수하는 방향을 보여 준다. 스킬 기반 에이전트 빌더 설계에 참고가 된다.

반응. HF 추천 FrameForge 112개, R^2Orch 87개. FrameForge GitHub 별 3개.
