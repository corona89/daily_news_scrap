1. Arete-27B: Qwen3.8-27B를 SFT로 다시 학습한 오픈웨이트 모델

출처. Nous Research (Hugging Face 모델 카드·블로그)

요약. Nous Research는 Arete-27B를 공개했다. 시작 모델은 Qwen3.8-27B이다. 파라미터는 27B이다. 라이선스는 Apache 2.0이다. 학습은 SFT만 썼다. 교사 모델은 Inkling이다. 토큰은 약 5,280만 개, 학습 문맥은 64k이다. 회사 평가(803개 프롬프트)에서 사실 점수는 2.32에서 2.98(5점 만점)로 올랐다. 선전 문구가 든 답은 22%에서 0.9%로 줄었다. Hermes Bench는 65.77%에서 65.60%이다. Terminal-Bench-2.1은 67%에서 70%이다. 회사는 이 차이를 자기 공으로 보지 않는다고 적었다. API 가격은 출처에 없음. 로컬 실행 하드웨어는 출처에 없음.

왜 중요한가. 중국 오픈웨이트 모델의 정치 편향을 소량 SFT로 바꿀 수 있다는 실험이다. 평가 데이터도 공개했다. 일반 성능 향상 모델은 아니다. 판정: 지켜볼 만함.

3. Hightouch: Jev가 어려운 건만 Opus에 넘기면 Opus 정확도를 4배 싸게 낸다
