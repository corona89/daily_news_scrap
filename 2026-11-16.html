1. Qwen4-Max: Qwen4 세대 첫 정식 모델 (가중치 비공개)

출처. Alibaba Cloud 보도자료(11-16), Qwen 블로그, Artificial Analysis, MarkTechPost·AgentsPulse 표 정리

요약. Qwen4-Max는 총 2.4T 파라미터 MoE이다. 토큰당 71B가 활성이다. 이는 Qwen3.8-Max보다 25% 적다. 문맥은 1M 토큰이다. 텍스트, 이미지, 영상을 입력으로 받는다. 가격은 입력 $1.50, 출력 $4.50(1M 토큰당)이다. 캐시 입력은 $0.075이다. 자체 표에서 DeepSWE v1.1 75.7(Opus 5.5 74.2, Kimi K3.1 75.5)이다. HLAB-Vals-1.1은 21.3(Kimi K3.1 11.7)이다. 하지만 Terminal-Bench 4.0은 48.5이다(Kimi K3.1 67.2). ProgramBench는 31.5이다(Opus 5.5 65.0). Artificial Analysis 지수는 43이다. 과제당 비용은 $3.27이다. 과제당 시간은 33.2분이다(중앙값 13.4분). 가중치는 공개하지 않는다. 로컬 실행은 불가능하다.

왜 중요한가. 중국 최상위 모델이 가격을 낮추었다. 그러나 독립 지수는 Kimi K3.1 Pro보다 낮다. 코딩 터미널 작업과 비전에서 약하다. Alibaba는 작은 Qwen4 오픈 가중치 모델을 곧 낸다고 한다. 로컬 사용자는 그 모델을 기다리면 된다.

반응. HN 847점, 댓글 468개. 댓글은 느린 속도, 높은 토큰 사용량, 27B 오픈 모델 기대에 집중했다. 링크: 원문 · Qwen 블로그 · Artificial Analysis · 벤치마크 표 · HN

2. Sage S2.1 Flash: 과학 연구용 320B 오픈 가중치 모델 (MIT)

출처. Hugging Face 모델 카드 (Shanghai AI Laboratory). 저장소는 11-15 11:34 KST에 생성되었다. 모델 카드 내용과 보도는 11-16에 나왔다.

요약. Sage S2.1 Flash는 320B, 활성 18B인 멀티모달 MoE이다. GLM-5.3-Flash 구조를 쓴다. 분자 그래프, 결정 구조, 단백질 구조 등 10종 이상의 과학 입력을 받는다. 자체 표 15개 중 4개에서 1위, 7개에서 2위이다. MLE-bench Lite는 90.3이다(DeepSeek-V4.1-Flash-1017 89.2). OfficeQA Pro는 72.2, SpreadsheetBench 2는 37.1이다. 반면 SWE-bench Pro는 60.6이다(Claude Opus 5 76.5). 라이선스는 MIT이다. BF16은 약 645GB이다. FP8 버전도 있다. 참고 배포는 H200 8장이다(orcarouter 분석). 문맥 길이와 가격은 모델 카드 기준 출처에 없음.

왜 중요한가. 상업 사용이 가능한 과학 특화 대형 모델이다. 문서·표 작업에서 Opus 5보다 높은 자체 점수를 냈다. 코딩에서는 뒤진다. 수치는 모두 자체 측정이다.

3. Haru-4B: 듣기와 말하기를 동시에 하는 음성 대화 모델

출처. Hugging Face 모델 카드, GitHub higurashi-ai/Haru. 저장소는 11-12에 생성되었다. 공식 발표는 11-13이다. 이번 기간에 HF 트렌딩 상위에 올랐다. 이전 다이제스트에 없었다.

요약. Haru-4B는 전이중(full-duplex) 음성 대화 기반 모델이다. 133ms마다 사용자 음성 한 프레임을 받는다. 같은 시간에 자기 음성과 텍스트 한 프레임을 낸다. 이산 오디오 토큰을 쓰지 않는다. 한국어를 포함한 9개 언어를 지원한다. 라이선스는 Apache-2.0이다. NVIDIA GPU 약 12GB로 로컬 실행이 된다. MLX 버전과 macOS 앱도 있다. 지시 수행 모델이 아니고 연구용 사전학습 모델이다. 벤치마크 수치는 출처에 없음.

왜 중요한가. 전화 통화처럼 끊김 없는 음성 에이전트를 로컬에서 시험할 수 있다. 한국어를 지원한다.

반응. HF 좋아요 416개, 다운로드 3,372회. GitHub 별 518개. 판정: 지켜볼 만함. 기반 모델이라 바로 쓰기 어렵다. 링크: 원문 · GitHub

4. Coral: 에이전트가 자기 도구를 코드로 쓰는 오픈소스 게이트웨이

출처. GitHub, Show HN

요약. Coral은 에이전트와 외부 시스템 사이에 놓는 자체 호스팅 게이트웨이이다. 에이전트는 짧은 TypeScript 프로그램으로 도구를 호출한다. 잘 된 프로그램은 사용자 도구로 저장해 다시 쓴다. 모든 호출은 Allow, Ask, Block 정책 검사를 거친다. 그 뒤에 Coral이 자격 증명을 붙인다. 보통 MCP 게이트웨이는 도구를 보이거나 숨기기만 한다. Coral은 도구 안의 규칙까지 정할 수 있다.

왜 중요한가. 에이전트에 도구 권한을 줄 때 범위를 좁게 정할 수 있다. 같은 작업을 반복할 때 토큰도 줄인다.

반응. HN 51점, 댓글 24개. GitHub 별 4,997개, Apache-2.0, 최신 릴리스 v1.8.0(11-13), 마지막 push 11-17 05:55 KST. 판정: 써볼 만함. 정책 기반 MCP 게이트웨이가 필요하면 바로 시험할 가치가 있다. 링크: 원문 · HN
