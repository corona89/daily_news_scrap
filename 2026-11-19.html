2. DaisyRose-27B (RadixArk, 오픈 가중치)

출처. RadixArk 블로그 (11-18), Hugging Face

요약. Qwen3.8-27B를 강화학습으로 후속 학습한 모델이다. 과제 1,200개로 18일 동안 H200 144장에서 학습했다. 세션은 최대 100만 토큰이다. Terminal-Bench 4.1 pass@1을 5.6%에서 12.0%로 올렸다. 회사는 모든 비교 벤치마크에서 기본 모델보다 높다고 한다. 학습 프레임워크는 오픈소스 Miles이다. 자체 백엔드 MFU는 37%이다. 오픈소스 Megatron 트레이너는 16%였다. BF16, FP8, NVFP4 체크포인트를 공개했다. 라이선스는 Apache-2.0이다. GGUF와 MLX 양자화가 이미 나왔다. 필요 하드웨어는 출처에 없음. 문맥 길이와 가격은 출처에 없음.

왜 중요한가. 적은 과제와 GPU로 에이전트 성능을 두 배로 올린 사례이다. 다만 절대 점수 12.0%는 아직 낮다. 평가: 써볼 만함(27B를 로컬에서 돌릴 수 있으면). 이유: 오픈 라이선스와 양자화 파일이 이미 있다.

반응. HN 247점, 댓글 104개. HF 좋아요 176. Miles GitHub 3,370 stars(Apache-2.0, 마지막 push 11-20). 링크: 원문 · 모델 카드 · Miles · HN

7. SuperEMeans: e-means 군집화 가속

출처. Leonardo Kuffo 블로그 (CWI)

요약. SuperKMeans와 e-means를 합쳤다. 고차원 벡터 군집화가 Lloyd k-means 대비 3배 빠르다고 한다. e-means 대비로는 최대 1.8배 빠르다. 테스트는 OpenAI 임베딩 500만 개(1536차원)와 Cohere 임베딩 1,000만 개이다. 같은 수의 벡터를 스캔할 때 검색 recall 손실이 없다고 한다. 장비는 Zen 5 16코어 1대이다.

왜 중요한가. IVF 벡터 인덱스 구축 시간을 줄인다. 평가: 써볼 만함(대규모 벡터 인덱스를 직접 만들 때). 이유: CPU·GPU 모두 지원하고 FAISS 대안이다.

반응. HN 61점, 댓글 0개. cwida/SuperKMeans 112 stars, MIT, 마지막 push 11-19. 링크: 원문 · GitHub · HN
