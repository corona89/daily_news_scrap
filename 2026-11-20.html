1. Hy4: Tencent의 770B MoE 오픈 가중치 모델

출처. Hugging Face 모델 카드, GitHub (11-20 갱신)

요약. Hy4는 Tencent의 새 플래그십 모델이다. 언어 본체는 총 770B 파라미터이다. 토큰당 활성 파라미터는 텍스트 49B와 비전 1.23B이다. 문맥은 1M(1,048,576) 토큰이다. 입력은 텍스트, 이미지, 영상이다. 추측 디코딩용 3.3B DFly2 드래프터가 들어 있다. Hy4, Hy4-FP8, Hy4 base 가중치를 공개했다. 모델 카드 그래프의 수치는 다음과 같다. Terminal Bench 4.0은 44.4%이다. GLM 5.3은 42.9%, DeepSeek-V4.1-Flash-1017은 40.0%, GPT 6.1 Sol은 55.5%, Claude Opus 5.5는 66.4%, Kimi K3.1 Pro는 66.8%이다. FrontierCode 2.0은 31.0%이다(Opus 5.5 46.4%). OSWorld 2.1은 78.9%이다(Opus 5.5 81.8%). 베이스 모델 MMLU-Pro는 73.9이다(DeepSeek-V4-Pro-Base 73.4). Tencent도 최상위 상용 모델과 차이가 남아 있다고 쓴다. 라이선스는 Tencent Hy License(자체 라이선스)이다. 예시 서빙은 GPU 8장(FP8, 텐서 병렬 8)이다. GGUF 버전이 있다. API 가격은 출처에 없음.

왜 중요한가. 오픈 가중치 모델 중 가장 큰 축에 든다. 에이전트 벤치마크에서 GLM 5.3, DeepSeek-V4.1-Flash보다 높다. 그러나 대부분 항목에서 Opus 5.5, Kimi K3.1 Pro보다 낮다. 로컬 실행은 서버급 GPU 8장이 기준이다. 11-18에 다룬 Hy4 flash의 상위 모델이다.

반응. HF 좋아요 122. GitHub 별 63. HN에는 System Card 글만 1점이다. X 뉴스에서 다뤘다. 링크: 원문 · GitHub · System Card · X 뉴스

2. Levent Alpöge, Claude와 함께 일반화 리만 가설 증명 주장

출처. alpo.ge PDF (11-20)

요약. 수학자 Levent Alpöge가 짧은 글을 올렸다. 그는 Claude와 함께 리만 가설의 증명을 찾았다고 쓴다. 같은 방법이 일반화 리만 가설(GRH)도 푼다고 한다. Lean 형식화를 마쳤다고 한다. Lean 파일은 14개 조각으로 공개했다. 그는 마지막 단계에서 Claude가 자신보다 앞섰다고 쓴다. 증명은 아직 매우 길다. 전문가 검증 결과는 아직 없다.

왜 중요한가. 사실이면 AI 보조 수학의 가장 큰 결과이다. Lean 증명이 있어서 검증이 빠를 수 있다. 같은 날 Terence Tao와 Scott Aaronson도 관련 글을 썼다(AFTER 참고).

3. Frostbite: AI가 설계·검증한 새 CPU 아키텍처

출처. Architect Labs 블로그 (11-18 미국 시간)

요약. Frostbite는 새 명령어 집합을 쓰는 범용 CPU이다. 계산 모델은 interaction net이다. AI 에이전트가 컴파일러, ISA, RTL, 검증, 최종 GDS까지 반복 설계했다. 7nm 공정에서 최종 GDS 기준 500MHz이다. 워크로드 25개에서 비교 CPU(듀얼 이슈 in-order 코어) 대비 전력당 성능이 4.59배이다(기하 평균). 튜닝에 쓰지 않은 15개에서는 3.83배이다. 면적당 성능은 평균 8.77배이다. 전력 수치는 실리콘 이전 추정치이다.

왜 중요한가. AI가 칩 아키텍처 탐색부터 레이아웃까지 맡은 사례이다. 다만 비교 대상은 작은 in-order 코어이다. 실제 칩 측정값은 아직 없다.

반응. HN 597점, 댓글 315개. 링크: 원문 · HN

4. Claude가 블랙홀 물리 미해결 문제 2개를 풀었다

출처. Anthropic 연구 블로그 (11-19 미국 시간)

요약. Anthropic 연구원이 Claude에게 열린 문제 목록을 만들게 했다. Claude는 후보 22개를 냈다. 문제마다 별도 에이전트를 두고 약 6주 동안 실행했다. 에이전트가 두 문제를 풀었다. 하나는 20년 넘게 풀리지 않은 Hawking-Page 전이 계산이다. 두 번째 결과는 9월에 Lean으로 형식 검증되었다. 물리학자가 주요 결과를 모두 확인했다. 페이지 제목에는 Claude Fable 5.2가 표기되어 있다.

왜 중요한가. 특별한 설정 없이 장기 에이전트가 연구 결과를 낸 사례이다. 사람 검토와 Lean 검증을 함께 썼다.

반응. HN 551점, 댓글 266개. 링크: 원문 · HN

5. Models Engineering Index: Gemini 4 Neon 1위

출처. MEI (오픈소스 지표 사이트)

요약. MEI는 코딩 벤치마크 16개를 합친 지수이다. 평균 모델이 50이 되도록 보정한다. Gemini 4 Neon이 68.4로 1위이다. GPT-6.2 Astra는 67.1, Claude Fable 5.2는 66.7, Opus 5.5는 61.5이다. 비용 배수는 Neon 2.1×, Astra 2.1×, Fable 5.2 5.8×이다. 오픈 가중치 중에서는 Hy4 42.8, GLM 5.3 42.0이다. 사이트는 오차 막대가 없다고 밝힌다. 작은 차이는 의미가 없다고 쓴다.

왜 중요한가. 상위 3개 모델의 차이는 2점 안이다. GPT-6.2 Sol은 60.6점이고 비용 배수는 0.54×이다.
