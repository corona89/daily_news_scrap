1. Inkling 2 Mini: Thinking Machines의 노트북용 루프 트랜스포머 오픈 가중치 모델

출처. Thinking Machines 블로그, Hugging Face 모델 카드 (11-20 미국 시간)

요약. Inkling 2 Mini는 MoE 모델이다. 총 파라미터는 26.4B이고 활성 파라미터는 3.4B이다. 중간 층을 토큰마다 세 번 반복 실행한다. 그래서 토큰당 가중치 활성은 5.4B이다. 문맥은 최대 1M 토큰이다. 입력은 텍스트와 이미지이다. 가중치는 대부분 NVFP4이고 마지막 4개 층은 MXFP8이다. 전체 크기는 약 20GB이다. 블로그 표의 수치는 다음과 같다. DeepSWE v1.1은 48.2%이다(Qwen3.8-27B 42.2%, Nemotron 3.5 Super VL 24.7%, Gemma 4 31B 0.3%). SWE-bench Pro v2 Hard는 77.9%이다(Qwen3.8-27B 73.8%). SWE-bench Verified는 79.2%이다(Qwen3.8-27B 77.8%). Terminal Bench v2.1은 71.6%로 Qwen3.8-27B(73.0%)보다 낮다. BrowseComp는 79.0%이다(Nemotron 3.5 Super VL 78.9%). AA Index v5.0은 20.1로 Qwen3.8-27B와 같다. 사실 지식 점수(AA-Omniscience)는 같은 크기 모델 수준이라고 회사가 쓴다. 라이선스는 Apache 2.0이다. 지원 하드웨어는 DGX Spark 1대, 메모리 32GB 이상 Apple silicon, VRAM 32GB 이상 GPU이다. HF 페이지의 PrimeIntellect 제공자 가격은 100만 토큰당 입력 $0.075, 출력 $0.3이다. 루프 수를 바꿀 수 있는 연구용 변형 모델도 함께 공개했다.

왜 중요한가. 100B 미만 오픈 가중치 모델 중 코딩 에이전트 벤치마크 최고 수준이다. 노트북에서 돌릴 수 있다. 루프 구조 모델을 공개한 사례가 드물어서 연구 가치도 크다. 평가 설정은 모델마다 다르다고 회사가 밝힌다.

2. Masullo의 GRH 증명안 공개, Lean 공동체는 Alpöge 증명 인증

출처. Ravi Vakil 블로그 (11-20), Lean 공동체 블로그 (11-21)

요약. Ravi Vakil이 Alessandro Masullo의 일반화 리만 가설(GRH) 증명안을 공개했다. AI를 쓰지 않은 사람의 증명이다. Brian Conrad가 몇 달 동안 검토했다. 약 8시간 뒤 Vakil은 문제점 보고를 받았다고 덧붙였다. 문제점은 여러 AI 모델의 도움으로 찾았다고 한다. 같은 날 Lean·Mathlib 공동체는 공동 성명을 냈다. Alpöge의 리만 가설 증명(Lean 1,700만 줄)이 맞다고 인증했다. 여러 독립 검사기가 증명을 확인했다.

왜 중요한가. 사람의 증명은 AI가 빠르게 검토했다. AI가 만든 증명은 형식 검증으로 확인되었다. 수학 검증 방식이 바뀌고 있다. Alpöge 증명은 11-20 본문 항목의 후속이다.

3. Navier–Stokes 방정식 유한 시간 폭발 증명과 Lean 형식화

출처. GitHub 저장소, Terence Tao 블로그 (11-20)

요약. Levent Alpöge와 Tristan Buckmaster가 79쪽 논문을 공개했다. 외력이 없는 3차원 비압축 Navier–Stokes 방정식에서 유한 시간 폭발을 증명한다고 한다. Lean 4 형식화도 함께 냈다. Lean 라이브러리는 약 2,270개 파일, 60만 줄이다. 증명에 쓰는 인증서 데이터는 아직 저장소에 없다. Tao는 두 사람이 AI를 많이 썼다고 쓴다. 그는 전문적인 증명 글이 더 필요하다고 쓴다. Euler 방정식 폭발 증명도 따로 나왔다.

왜 중요한가. 밀레니엄 문제 하나와 관련된 결과이다. AI 보조와 형식 검증을 함께 쓴 사례이다. 인증서 공개 전까지 전체 검증은 끝나지 않는다.

반응. 저장소 HN 312점, 댓글 104개. Tao 글 HN 531점, 댓글 236개. GitHub 별 316(라이선스 표시 없음, 마지막 푸시 11-20). 링크: 원문 · HN · Tao 블로그 · HN Tao

4. 논문: 언어 모델이 자기 가중치를 다시 쓸 수 있다

출처. arXiv 2611.21885 (v2 11-18)

요약. 오픈 27B 모델에게 자기 가중치, 채점된 답, 자기 실행 권한을 주었다. 모델은 실패 원인을 찾고 가중치를 직접 고쳤다. 경사 하강도 학습도 쓰지 않았다. 처음 보는 문제에서 정확도가 6.6점 올랐다. 8번 연속 세션에서 정확도가 계속 올랐다. 손상된 사본을 원래 정확도의 80% 이상으로 복구했다. 같은 계열의 작은 모델은 수정하지 못하거나 스스로를 망가뜨렸다.

왜 중요한가. 추론만으로 가중치를 개선하는 새 방법이다. 답변마다 추가 비용이 없다. 재현과 안전성 검토가 필요하다.
