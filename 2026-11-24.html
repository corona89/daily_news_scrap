1. Raon-1 mini: KRAFTON이 처음부터 학습한 30B-A4B MoE (Apache 2.0)

출처. Hugging Face 모델 카드 (KRAFTON, 11-24 22:17 KST 생성)

요약. Raon-1 mini는 KRAFTON AI가 처음부터 학습한 MoE 언어 모델이다. 총 28.8B, 활성 4.3B이다. 문맥은 262,144 토큰이다. 25개 층 중 18개는 선형 어텐션(Raon Delta Attention)이고 7개는 MLA이다. 라이선스는 Apache 2.0이다. 카드의 MoE 비교(Qwen3.6-35B-A3B, Gemma 4 26B-A4B, Inkling 2 Mini)에서 GPQA Diamond는 86.0(83.2, 80.7, 86.6)이다. MultiChallenge는 64.9로 비교 MoE 중 가장 높다. BrowseComp Plus는 55.9이다. SWE-Verified는 71.0이고 Inkling 2 Mini(74.2)보다 낮다. 내부 한국어 대화 평가는 92.7이다. 2027 수능 전체(450점, 문항별 입력)는 401.3점이다. NVFP4판은 RTX 5090(32GB) 1장에서 돈다고 쓴다. 가격은 출처에 없음.

왜 중요한가. 한국 회사가 자체 학습한 오픈 가중치 모델이다. 활성 4.3B라서 단일 GPU에서 돌릴 수 있다. 한국어 평가는 내부 벤치마크라서 외부 검증이 필요하다.

4. VP ≠ VNP over Every Field: Claude가 찾은 대수 복잡도 증명

출처. Anthropic GitHub (formal-math). Hacker News

요약. Anthropic이 논문과 Lean 4 형식화를 공개했다. 모든 체에서 해밀턴 순환 다항식 회로는 m^(c(log m)^(1/3))개보다 많은 게이트가 필요하다고 증명한다. 그래서 VP는 VNP의 진부분집합이라고 결론 낸다. 이 결과는 P vs NP를 풀지 않는다. 내부 연구용 Claude 모델이 결과를 찾았다. 논문과 Lean 코드는 AI가 썼다. 사람 수학자는 아직 증명을 검토하지 않았다. 라이선스는 Apache 2.0이다.

왜 중요한가. 대수 복잡도 이론의 핵심 미해결 문제를 AI가 풀었다는 주장이다. Lean 검사는 통과하지만 명제가 원래 주장과 같은지는 사람이 확인해야 한다. AFTER에 OpenAI도 같은 결과를 먼저 풀었다고 주장했다.

반응. HN 357점 / 댓글 329개. 링크: 원문 · HN

5. Shirudo: OpenAI·Cisco의 eBPF 기반 오픈소스 보안 런타임

출처. OpenAI 공식 블로그 (11-23). GitHub. Hacker News

요약. Shirudo는 패치 전 Linux 시스템을 재시작 없이 보호하는 런타임이다. eBPF 프로그램인 "shield"로 취약한 코드 경로를 막는다. shield는 서명 검증을 거쳐 올라간다. TPM으로 적용·제거 기록을 남긴다. 통제 실험에서 Codex가 만든 shield가 실행 중인 Elasticsearch의 Java4Shell 공격을 막았다. GitHub 저장소는 별 1,673개이고 마지막 push는 11-25이다. 라이선스는 BSD-2-Clause이고 BPF 코드는 BSD/GPL 이중이다. 평가: 지켜볼 만함. 공개 초기이고 운영 사례가 아직 없다.

왜 중요한가. AI 에이전트가 임시 방어 코드를 만들고 사람이 승인하는 구조이다. 패치 공백 기간을 줄이는 방법이다.

반응. HN 83점 / 댓글 25개. GitHub 별 1,673개. 링크: 원문 · GitHub · HN

6. Claude Ship(베타): PR 검토·수정·승인을 맡는 Anthropic 에이전트

출처. Anthropic 글 (11-23). Hacker News

요약. Claude Ship은 Code Review(정식), PR Steward(베타), Claude Approvals(베타)로 구성된다. PR Steward는 실패한 CI, 병합 충돌, 리뷰 의견을 고친다. PR Steward는 승인과 병합을 하지 않는다. Claude Approvals는 저장소의 정책 파일에 따라 일상 변경을 승인한다. Claude Code에서 /ship 명령으로 쓸 수 있다. Claude Code 팀에서는 6월부터 9월까지 병합 PR이 2배 넘게 늘었다. 되돌린 PR 비율은 40% 넘게 줄었다. 가격은 출처에 없음.

왜 중요한가. 코드 작성 뒤의 검토·승인 단계까지 에이전트가 맡는다. 처음에는 관찰 전용 모드로 켜라고 회사가 권한다.

반응. HN 86점 / 댓글 32개. 링크: 원문 · HN
